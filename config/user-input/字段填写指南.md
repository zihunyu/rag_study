# 配置文件字段填写指南

你不需要先学会 YAML，也不需要理解所有技术名词。

当前配置分成三类：

1. **需要你决定的内容**：负责人、第三方服务地址、模型名称、数据保存时间和预算。
2. **开发程序负责确定的内容**：模型维度、是否归一化、版本探测、超时、并发、端口和本地路径。
3. **敏感信息**：Token、API Key 和密码，只填写到 `.env.user.local`，不要写入 YAML，也不要发送到聊天中。

主配置文件是 `project-inputs.yaml`。你现在只需要处理下面列出的字段；没有列出的字段暂时不要修改。

## 一、最简单的填写方式

你可以不直接编辑 YAML，只需把本文第八节的中文表格复制到聊天中，填写非敏感内容。开发任务会把答案写入 YAML。

Token 不要填在聊天表格中。打开 `.env.user.local`，在自己电脑上填写即可。

## 二、负责人信息

配置位置：`project.owners`

| 字段 | 中文含义 | 怎么填 |
| --- | --- | --- |
| `product_project_manager` | 决定做什么、控制范围和进度的人 | 填姓名，例如 `张三` |
| `technical_architect` | 决定技术方案的人 | 一人项目可与上面填同一姓名 |
| `security_compliance` | 决定敏感数据和安全要求的人 | 没有专人时先填自己，并写“暂代” |
| `sre_operations` | 负责启动、备份和故障处理的人 | 一人项目可填自己 |
| `qa_evaluation` | 负责测试和效果验收的人 | 一人项目可填自己 |
| `business_uat` | 最终确认回答是否符合业务的人 | 最好填实际使用知识库的人 |

如果目前只有你一个人，可以六项全部填写：

```yaml
owners:
  product_project_manager: "你的姓名（暂代）"
  technical_architect: "你的姓名（暂代）"
  security_compliance: "你的姓名（暂代）"
  sre_operations: "你的姓名（暂代）"
  qa_evaluation: "你的姓名（暂代）"
  business_uat: "你的姓名（暂代）"
```

这里填写的是负责人姓名，不是用户名、密码或公司名称。

## 三、文档容量

你已经给出的配置如下，不需要再次填写：

- 首批文档：3,000 份；
- 每日新增或更新：200 份；
- 同时问答：50 个请求；
- 本地存储上限：100 GB；
- 初步估算：150,000 个 Chunk。

目前只剩一个字段：

### `capacity.annual_growth_percent`

含义：一年后，文档总数预计比现在增加百分之多少。它只计算净新增文档，不计算同一文档的更新次数。

示例：

- 现在 3,000 份，一年后约 6,000 份：填 `100`；
- 一年后约 9,000 份：填 `200`；
- 完全不知道：可以先填 `100`，试运行一个月后按真实数据调整。

推荐本地试点先填：

```yaml
annual_growth_percent: 100
```

## 四、第三方 AI 服务

你需要分别提供四类服务。它们可以来自同一家第三方平台，也可以来自不同平台。

### 4.1 什么是 Base URL？

Base URL 是第三方平台提供的 API 基础地址，例如：

```text
https://api.example.com/v1
```

通常不要填写到具体接口：

```text
错误示例：https://api.example.com/v1/chat/completions
正确示例：https://api.example.com/v1
```

如果服务商文档明确要求完整地址，则按服务商文档填写。

### 4.2 LLM：生成最终答案

配置位置：`ai_services.llm`

| 字段 | 你填什么 | 示例 |
| --- | --- | --- |
| `endpoint` | LLM 的 Base URL | `https://api.example.com/v1` |
| `model_id` | 服务商要求传入的精确模型名 | `example-chat-model` |
| `model_revision` | 你不需要填写；没有版本概念时由开发任务填 `provider_managed` | `provider_managed` |
| `timeout_seconds` | 你不需要填写；开发任务先用 `120` 并通过测试调整 | `120` |
| `max_concurrency` | 你不需要填写；开发任务先用 `10` 并通过限流测试调整 | `10` |

Token 填到：

```dotenv
LLM_API_KEY=这里填写真实Token
```

### 4.3 Embedding：把文档和问题转换成向量

配置位置：`ai_services.embedding`

| 字段 | 你填什么 | 示例 |
| --- | --- | --- |
| `endpoint` | Embedding 服务 Base URL | `https://api.example.com/v1` |
| `model_id` | 精确 Embedding 模型名 | `example-embedding-model` |
| `model_revision` | 你不需要填写；没有版本概念时由开发任务填 `provider_managed` | `provider_managed` |
| `max_concurrency` | 你不需要填写；开发任务探测后回填 | `10` |
| `dimension` | **不要猜，由程序调用一次模型后自动确定** | 暂时保留 `__FILL_ME__` |
| `normalize` | **由开发程序根据模型和距离函数确定** | 暂时保留 `__FILL_ME__` |

Token 填到：

```dotenv
EMBEDDING_API_KEY=这里填写真实Token
```

同一个知识空间更换 Embedding 模型后必须重建向量索引，不能只改模型名称。

### 4.4 Reranker：把检索结果重新排序

配置位置：`ai_services.reranker`

| 字段 | 你填什么 | 示例 |
| --- | --- | --- |
| `endpoint` | Reranker 服务 Base URL | `https://api.example.com/v1` |
| `model_id` | 精确 Reranker 模型名 | `example-reranker-model` |
| `model_revision` | 你不需要填写；没有版本概念时由开发任务填 `provider_managed` | `provider_managed` |
| `max_concurrency` | 你不需要填写；开发任务探测后回填 | `5` |

Token 填到：

```dotenv
RERANKER_API_KEY=这里填写真实Token
```

### 4.5 ASR：处理音频

配置位置为 `ai_services.asr`；音频已提前进入 R1。

| 字段 | 你填什么 | 示例 |
| --- | --- | --- |
| `provider` | 服务商名称或 `openai_compatible_third_party` | `openai_compatible_third_party` |
| `endpoint` | 音频转写服务 Base URL | `https://api.example.com/v1` |
| `model_id` | 精确语音转文字模型名 | `example-asr-model` |

Token 填到：

```dotenv
ASR_API_KEY=这里填写真实Token
```

如果当前第三方平台没有语音转文字模型，音频功能暂时无法完成，需要再选择一个 ASR 服务。

### 4.6 MinerU：解析 PDF、Word、PPT、Excel 和图片

项目需要同时支持两种方式：

1. MinerU 官网托管接口；
2. 自建 MinerU 接口。

托管接口地址已经配置，不需要你填写：

```text
https://mineru.net/api/v4
```

托管 MinerU 的 Token 填到：

```dotenv
MINERU_TOKEN=这里填写MinerU的真实Token
```

自建地址默认是：

```text
http://127.0.0.1:8000
```

`ai_services.mineru.version` 不需要你猜。安装 MinerU 后由程序读取实际版本并回填。

OCR 已经由 MinerU 负责，因此默认不需要填写 `OCR_API_KEY`。只有以后改用独立 OCR 服务时才填写。

## 五、安全和数据保存时间

配置位置：`security_compliance`

以下内容需要你作业务决定，不是技术参数。

### `legal_hold_required`

含义：文件即使被用户删除，是否仍因法律、诉讼、审计或监管要求不能真正清除。

- 普通内部知识库、没有此类要求：填 `false`；
- 涉及诉讼、金融监管、档案强制保存：填 `true`；
- 不知道：先向公司法务或负责人确认，不建议开发人员替你决定。

### 保存天数

| 字段 | 含义 | 没有公司规定时的试点建议 |
| --- | --- | --- |
| `online_content_retention_days` | 在线原文件和解析内容保存多久 | `365` |
| `backup_retention_days` | 备份保留多久 | `30` |
| `audit_retention_days` | 操作审计日志保留多久 | `180` |
| `tenant_offboarding_purge_days` | 停用租户后多少天完成清除 | `30` |
| `audit_worm_target` | 不可篡改审计存储位置 | 本地试点填 `local_append_only`，生产前重新确认 |

示例：

```yaml
legal_hold_required: false
audit_worm_target: local_append_only
online_content_retention_days: 365
backup_retention_days: 30
audit_retention_days: 180
tenant_offboarding_purge_days: 30
```

你已经允许数据发送给第三方 AI 服务，但当前仍配置为“不允许跨境传输”。如果第三方服务的数据处理区域不在你批准的地区，仍然不能使用。需要向服务商确认：

- 数据在哪个国家或地区处理；
- 是否保存请求正文；
- 保存多长时间；
- 是否会用于训练；
- 是否提供关闭日志或零数据保留选项。

## 六、预算

配置位置：`slo_and_finops`

币种已经设置为人民币 `CNY`。你只需要填写三个数字：

| 字段 | 含义 | 填写示例 |
| --- | --- | --- |
| `max_cost_per_ask` | 一次问答最多接受多少人民币 | `1.00` |
| `max_cost_per_1000_pages_ingested` | 解析和向量化 1,000 页最多多少人民币 | `100.00` |
| `monthly_budget` | 每月总预算上限 | `1000.00` |

这些数字不是市场价格，只是费用熔断线。超过时系统停止或降级，避免意外产生大量费用。

如果暂时不知道预算，可先填写你愿意承担的试点上限。例如每月最多愿意花 500 元，就填 `monthly_budget: 500`。

## 九、`.env.user.local` 怎么填

本地开发实际需要的通常只有以下变量：

```dotenv
MINERU_TOKEN=
LLM_API_KEY=
EMBEDDING_API_KEY=
RERANKER_API_KEY=
ASR_API_KEY=
```

填写规则：

- 等号左边不要改；
- 将真实 Token 填在等号右边；
- 不要加中文引号；
- Token 中包含 `#` 或空格时使用英文双引号；
- 不要把该文件发送到聊天、邮件或截图中；
- 当前本地适配器不需要 MySQL、Milvus、RabbitMQ、Redis 和 OIDC 密钥，这些项可以保持空白。

## 十、这些字段不要手动修改

下面字段已经由开发约束或本机检查确定：

- `input_version`、`status`、`last_updated_at`；
- `target_platform`、`docker_forbidden`、`startup_commands`；
- 本地存储路径、SHA-256 和原子写入要求；
- MySQL、Milvus、RabbitMQ、Redis 的本地适配器模式；
- `embedding.dimension` 和 `embedding.normalize`；
- MinerU 实际版本；
- 模型超时和并发的最终值；
- ADR 架构审批字段；
- SLO、RPO/RTO 和发布评测阈值。

这些字段应由开发任务通过服务探测、测试或架构审核回填，不应让非技术用户猜测。
