# 数字归属、图号与答案关键条件修复

## 已修复行为

1. **数字与表格归属**：独立 OCR 不再只检查数字是否出现。数值表格使用真实文字框，对全部非空单元格做行列顺序、同行对齐、同列对齐及合并单元格约束；必须存在唯一对应方案，才能确认数值与型号、表头的归属。交换 A/B 的 100 W、200 W，或交换表头，都不能通过。重复数值可以由行列位置消歧；缺少坐标、表头未能定位、多解或超出求解预算时明确待复核，不生成假位置。
2. **中文数字与单位**：识别紧贴中文的数字、全角数字、符号、科学计数法、区间和常见中英文单位。保留单位大小写，不能用 323 证明 23、用 MW 证明 mW，或用一个端点证明完整范围。视觉描述中的对象计数由独立视觉复核负责，避免把“图中有三个节点”误当成原图必须印有数字 3。
3. **图号身份**：检索关联与排除范围共用完整图表编号解析；区分图1、图10、图1.2、图1.20以及图/表。支持中英文名称和空格，章节数字后缀也按完整编号匹配。排除父章节时会检查子章节图片的明确引用。隐含语义依赖仍保留人工独立性确认。
4. **关键条件遗漏**：从本轮有效原文提取适用条件、例外、限制、流程分支和条件表格行。章节提要即使漏选条件，其完整来源块仍保留到证据预算选择中；预算不足明确提示缺口。独立答案复核逐项返回“已保留、缺失、与本题无关”，已保留必须有答案中实际存在且非空泛的对应片段。仅引用某一章不算条件已覆盖。缺失时最多重新组织一次答案，重新检查引用、权限和全部事实；仍遗漏则不展示、不写入答案缓存。

问答页面显示关键条件核对数量。历史报告只保存对用户可见的计数，不在这里附带撤回后可能失效的原文摘录。

## 已发布文档和缓存

图片辅助检查带独立版本号；旧缓存不能跳过新的检查。问答遇到旧发布图片时，用已有独立 OCR 坐标重新检查，必要时读取原图；核对失败的图片与包含旧图片文字的父块同时排除。不会后台改写文档或发布版本。人工确认的修订保留其审核归属，问答仍需通过本轮视觉与答案验证。

答案复核版本已升级，旧答案缓存不能绕过新条件检查。图片问答还明确区分“本图内容看不清”和“本图没有涉及的其他主题”：一张清晰参数图可以支持复合问题中的功率部分，其他来源继续回答维修政策；图内真正的歧义或冲突仍会阻止使用。

## 检查边界

条件清单结合规则和独立模型检查，不能保证任意语言、隐含前提、复杂版式零遗漏。一次最多逐项核对 64 条去重后的条件，原文条件摘录合计最多 18000 字符；超限明确要求缩小资料范围。表格无法建立可靠位置关系时允许人工对照修订，不以“数字都出现过”降低通过标准。
