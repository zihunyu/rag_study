# 流程图问答与人工复核

本次修复对应 `artifacts/reviews/20260908-visual-rag-audit/源码审查与流程图问答改进.md`。保留原图、历史版本与审核记录；Mermaid 用于展示，问答依据是当前已发布版本的确认事实。

## 如何处理“待复核”

1. 打开文档详情的“原图与识别”，选择待处理图片，点击“修订这张图”。页面会定位到编辑器。
2. 对照原图修改节点、分组、连线或表格。可以增删对象、修改所属分组和节点形状、编辑判断分支、调整表格行列及合并单元格。
3. 逐项填写问题处理结果：**识别有误，已经修正**、**已核对，原识别正确**，或 **无法确认，排除相关对象**。修正必须绑定确实修改的对象；说明中写明核对位置和依据。不能只清空警告。
4. 可在原图上框选节点或连线位置。这里使用原图坐标，不能拿 Mermaid 重排后的坐标代替。
5. 保存后生成新版本。检查质量报告和保留范围，通过“确认发布”后用于问答。旧版本与原有审核记录继续保留。

排除节点或分组时，相关连线和子对象一起隔离。排除后的图只提供独立的确认事实；旧图片说明、转录、混合父块和缓存不能重新带回被排除的关系。回答完整流程时，如仍有未确认分支，会明确说明缺口。

编辑开始时固定版本条件。期间出现更新，保存会提示刷新；不会静默取得新条件后恢复旧正文。查看历史版本时，普通修订被阻止，只有明确选择历史恢复并确认最新版本差异，才允许创建恢复版本。

## 已修复的链路

| 环节 | 行为 |
|---|---|
| 图中对象身份 | 无标题容器以明确的生成说明表示；同名组件保留分组、实例及来源身份，不再合并成同一个名称 |
| 两次识别比较 | 先对应具体实例，再核对父分组、端点、方向、线型、形状和分支条件；内部 ID 不同不等于内容不同 |
| 独立数字核对 | 使用真实 OCR 区域绑定对象，再比较数字和单位；A/B 数值互换不能凭全图包含这些数字通过 |
| 人工复核 | 完整结构编辑、逐问题记录、真实原图区域、版本冲突保护及局部排除 |
| 关系检索 | 直接连接、有界路径、从入口展开的下游分支与循环；不会把架构连线推测成执行顺序或并行语义 |
| 图像证据 | 人工确认的结构直接参与问答；模型确认图片按问题复查。候选图片按相关性分配预算，并为补查留出容量 |
| 条件补写 | 核验发现的有效条件来源真正进入重写证据，随后重新核验事实、条件和引用 |
| 引用 | 每个图事实声明绑定具体事实 ID；只有使用过、当前有效的事实可标为答案来源。无可信坐标时显示原图，不伪造定位 |
| 多图 | 明确的图号引用可以补查对应图片；同名组件不会自动跨图合并成一条路径 |
| 运行状态 | Worker 独立心跳、任务停滞判断、账号内问答优先且后台不会永久饿死、本地 OCR 有界并行 |
| 用量 | 增量汇总及原始调用记录归档；归档后保留累计统计，未配置单价的调用仍标为未定价 |
| 评测 | 真值评测与线上比较器分离，增加无标题容器、重复实例、判断分支、循环、局部排除与引用定位回归 |

## 旧已发布图文的安全重建

仅支持最新且正在生效、来源完整、已人工复核的版本。脚本默认干运行并备份原文件、图片、审核记录、原始解析和当前分块；不重新识别，也不生成新的人工确认。

```powershell
.venv/Scripts/python.exe scripts/rematerialize_visuals.py --version-id <已发布版本ID>
.venv/Scripts/python.exe scripts/rematerialize_visuals.py --version-id <同一版本ID> --apply --plan <上一步的diagnostic.json>
```

应用时核对备份指纹、当前版本和文档条件，只创建新草稿。检查解析内容及质量后走正常发布流程。重复提交同一计划返回同一任务；来源变化、撤回、删除或出现更新版本时，旧计划不能恢复它。

结构重建不重新调用视觉识别模型；新分块仍走正常向量生成与索引流程，因此不能将“零次视觉识别”解释为所有模型调用和费用均为零。

新增接口及字段已纳入 `docs/openapi/openapi.json`。新用量表在原有视觉账本上增量创建，不清空文档或问答数据库。配置新增项见 `config/.env.example`；默认值可直接使用。

## 能力边界

- 裁切、遮挡、低清晰度导致的未知内容仍需清晰原图或人工确认；程序不会为通过复核而猜测连线。
- 查询有步数、证据和调用预算。超过范围会报告缺口，不把已读片段称为整份资料的完整结论。
- 明确图号引用不等于节点之间已有连接。跨图完整路径需要资料中明确的连接证据。
- 合成回归验证具体故障，不代表所有业务图的总体准确率。实际验收记录与最初失败样本存放在 `artifacts/reviews/20260908-visual-rag-fix/`。
