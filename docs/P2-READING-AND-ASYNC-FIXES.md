# 读取与异步状态修复

## 验证器错误

`TransientProviderError` 映射为 `system_error`、`CLAIM_VERIFIER_UNAVAILABLE`、
`retryable=true`。`InvalidProviderResponse` 和 `ValueError` 映射为
`CLAIM_VERIFIER_PROTOCOL_INVALID`，保持 `retryable=false`；协议错误需要修正输出契约，
不通过无差别重试掩盖。两类错误均不放行答案、不签发引用、不写答案缓存。
JSON、SSE 和持久化结果使用相同的标记，响应不包含上游异常详情。

## 分页关联读取与文档授权

MySQL 文档分页使用一个连接：校验空间、读取本页 ID、批量读取文档、批量读取当前或
最新版本、批量读取对应会话、批量统计分片。最新版本和对应会话在数据库内用
`ROW_NUMBER()` 分组选择，每组只返回一条；保持版本序号、实体 ID 的原排序规则。
当前版本分支按文档记录中的版本 ID 批量加载，仍检查版本归属。

SQL 测试在已完成迁移检查的仓库实例上，测得每页 1 篇和 20 篇均为 **1 个连接、6 次查询**。
样例包括 25 篇文档、每篇 5 个版本、每版本 2 个会话；验证当前／最新版本、会话对应关系、
游标、租户／索引代际隔离及排除父段落后的分片计数。此计数只覆盖仓库分页方法，
不代表整个 HTTP 接口的 SQL 总数。

文档可读性使用带完整分片权限条件的 `SELECT 1 … LIMIT 1`：租户、知识库、文档与版本、
ACL、密级、有效期、发布状态、当前版本和权限修订；生产 MySQL 还限定索引代际。
不将同一文档权限假定为一致，也不拉回分片 ID 或正文进行循环扫描。
删除了生命周期检查前的重复刷新；保留查询前的版本快照和查询后的权威状态复核，
防止查询期间的撤权、版本或权限修订切换被旧投影放行。

本地 SQLite／内存适配器继续采用已有单代际语义。回归覆盖不同分片权限、过期、
密级、旧版本／权限修订，以及 1,200 个无权限分片的拒绝路径和查询期间撤权。

这里使用 SQLite 执行 MySQL SQL 测试框架，适配占位符、时间和 JSON 重叠函数，
不是 MySQL 集成或压力测试。数据库内部仍需评估候选分片及本页文档历史；
没有执行生产 `EXPLAIN`、并发压测或给出延迟／吞吐量结论。

## 前端请求与版本身份

- 引用同时校验独立引用请求序号、答案序号和答案对象身份；成功及异常分支采用同一检查。
- 文件哈希校验文件对象及文件请求序号，与知识库／文档选择解耦；取消或换文件使旧任务失效。
  就绪状态和按钮由有效 SHA-256 驱动，失败状态不会在切库时被误标为已就绪。
- 统一版本切换同时更新管理目标与显示目标，清空分片、分页游标、加载状态、质量与复核结果。
  上传初始文档和新版本都接入该流程，新版本进入明确的管理预览入口。
- 解析监控绑定知识库、选择序号、版本、任务与上传流程序号；完成后加载同一版本的质量报告
  和分片，即使该版本未出现在当前第一页列表中。离开选择后丢弃旧结果与旧错误。
- 分块面板标题显示所展示的版本 ID。

Vue DOM 回归以可控异步响应验证 E1／E2 乱序、哈希期间切库／换文件／取消、
V1 分块分页未完成时上传 V2，以及解析完成前切换知识库或文档。

## 验证结果

- 后端全量本地回归：778 通过；4 个本地服务测试未启用；37 个集成测试按默认配置未运行。
- 分页与授权专项：42 通过；包含最终版本的代际隔离断言。
- 前端：25 个 Vue 组件测试、11 个 API／哈希测试、1 个配置测试通过，Vite 生产构建通过。
- Ruff 检查、Mypy（188 个源文件）、OpenAPI 快照校验及差异空白检查通过。
- 全仓库格式预检发现既有未格式化文件；仅格式化本次涉及文件，未改动无关文件。
