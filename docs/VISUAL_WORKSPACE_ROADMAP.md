## 范围与验收

1. 来源与覆盖：检查图形对象、页面渲染兜底、PPT/Excel 真实锚点、覆盖状态；逐图阶段、引用区域、刷新保留位置；人工标注样本与调用统计。
2. 可信内容：独立 OCR 和可独立配置的视觉复核、数字/单位/箭头专项检查；可追溯修订、单图重试、新版本差异；按完整依赖范围排除内容后发布，未通过内容不能从任何检索来源返回。
3. 完整性与效率：全文逐章读取、带出处的章节提要、跨图明确关联、覆盖检查；有界并发、跨版本缓存、供应商账号统一限流，耗时和费用可见。

## 实际验收（2026-09-07）

专用库：**图片三阶段综合验收-20260907**。`Orion-six-images.docx` 有六个不同章节和六张独立参数表：323 W、23 mW、220 V、24 V、64 GB、2 A。

2. 真实逐章问答读取 18 个片段、核对全部六图，六个组件参数均回答正确并引用各自来源。联调发现“单图被要求证明全部六章”和缺少图外章节上下文的问题，已修正为每图核对自身贡献，仍拒绝不清楚或冲突证据。

4. 排除第六章生成版本 3：五图可用、一图排除，原文片段中没有被排除章节的参数。询问最大电流返回资料不足，没有借用历史回答中的 2 A；版本 1 引用已失效。
5. 版本 3 再次逐章总结，五个保留组件参数正确，覆盖报告明确指出第六章被排除。

## 仍须明确的边界

- 未填写模型单价，当前费用显示未知；token 与调用次数来自实际响应。
- 图片/片段/token/时限有明确预算，全文或跨图超过预算会显示缺口。复杂交叉箭头、低清晰度、重复文字仍可能需要人工核对。
- 外链图需要嵌入文档；转换器无法处理的对象、缺页或超限内容不作为完整识别发布。Mermaid 表达结构，不复刻原图排版。
- 独立模型复核与 PP-OCRv4 增加了交叉检查，不能保证任意资料零错误。旧业务版本不会后台重写；要采用新拆分和图形处理，需要重新识别为新版本后复核发布。
