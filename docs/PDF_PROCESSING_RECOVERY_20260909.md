# 第 6 版 PDF 处理失败与恢复

文档：西药二润德速记口诀0607.pdf。
版本：`01a08342-6820-76b8-bbb3-dbdd4ad4dce4`。
任务：`01a08342-6829-7f0d-9d6a-263119e23cb3`。

## 已确认的失败原因

1. MinerU 完整解析成功，覆盖 141 页，返回 1741 个原始节点，结果 ZIP 已持久化。
2. PDF 只有第 12 页的一张插图进入补充识别。识别模型 `gpt-5.5` 返回 HTTP 200，
   用时约 32.48 秒；独立复核模型 `gpt-5.4-mini` 随后返回 HTTP 400。
3. 视觉分析器未捕获 `InvalidProviderResponse`，异常从插图处理一直传播到文档任务，
   Worker 将任务标为 `INGEST_PERMANENT / FAILED_FINAL`。正文尚未保存到 Canonical
   Document，因此界面显示 0 个分块。原始 400 的响应正文没有保存，无法确定当时具体参数错误。
4. 诊断时再次调用相同图片复核接口，供应商返回 HTTP 429，明确提示：
   `All available accounts are currently rate-limited. Please retry later.`
   这是当前实测的上游限流状态，不把它推断成原始 HTTP 400 的原因。

## 修复

图片分析遇到明确的供应商响应异常、限流、超时或临时不可用时，保存已获得的识别候选，
将图片标为待复核，并记录失败阶段、稳定错误码及可取得的 HTTP 状态码。传输层有界重试
耗尽后，不再通过修改识别提示词重复调用。未知程序错误和用户取消继续传播。

正文继续保存和建立索引；未复核的图片仅保留不可用于问答的占位说明，并通过
`VISUAL_REVIEW_REQUIRED` 阻止直接发布该版本，避免把未核对的图片内容当作可信证据。
