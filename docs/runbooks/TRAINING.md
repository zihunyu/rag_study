# 试点培训提纲（合成环境）

- 知识维护者：上传、质量复核、发布 readiness、回滚、删除与 cleanup 状态；
- Reader：可信问答六状态、引用预览、反馈与越权不泄露语义；
- SRE：原生进程、健康检查、diagnostics/alerts、queue retry、tombstone-first 恢复；
- 安全：RBAC、签名引用、Prompt injection 合成用例、外部出站策略；
- 试点负责人：Go/No-Go、VETO、灰度批次、rollback trigger、UAT/defect；
- 验收负责人：7 天观察窗、P0/P1 gate、四方签字和最终 BLOCKED 报告。

本提纲只对应 simulated 环境，真实培训记录留最终统一验证。
