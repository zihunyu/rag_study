## 本次修复

- 当问题明确对应某个来源章节的编号清单时，从当前授权、有效版本的原文提取连续条目，统一输出 `1.`、`2.` 等编号。代码没有药物名称、固定十条或本题答案。
- 回答明确注明“按所引资料的章节编号逐条整理”。核验器检查该来源归属，不应仅凭模型自己的分类删除原文条目；事实、实体、条件和全证据冲突核验仍全部执行。
- 同一版本、相同章节内的短摘录与包含它的较完整条目保留较完整原文。完全相同但原编号不同的段落合并引用，避免再次作为“相关限制”追加。数字、正负号、小数、比较符号或正文不同的版本不能按排版差异合并。
- 保存预期和实际条目数；即使模型核验给出通过，后续修复或缓存答案若丢失、改写、重排清单条目，仍拒绝发布，并显示具体失败原因。
- 范围不同、用户只问某一项、要求摘要、跨文档来源歧义、编号断裂或条款不同等情况继续走通常的问答流程，不擅自选定清单。

此处“完整”只对应已确定的原文编号清单，不代表整份知识库或外部专业知识已经穷尽。文档解析、发布状态和 MinerU 流程没有调整。
