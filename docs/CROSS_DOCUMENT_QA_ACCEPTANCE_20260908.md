## 判定标准与环境

- 有充分资料：回答包含所问事实，数值与对象对应正确，引用覆盖必要文件并可定位原文；回答必须经过核验。
- 有关键条件：保留适用范围、并列前提、否定例外、预约要求和时间条件。
- 资料不足：允许拒答，或明确指出缺失的子问题；不得补造电话、金额、电压等值。
- 当前有效资料互相矛盾：应报告冲突，不得任意选择其中一个答案。
- 收窄文件范围、其他知识库及未发布文件：范围外资料不得进入当前证据或充当回答依据。

页面验收沿用 `重设计验收库-20260906` 中的 Markdown 手册、CSV 参数表和 Word 合同。
全程通过已登录浏览器提问，生成模型为 `gpt-5.5`，核验模型为 `gpt-5.4-mini`。

临时库不会向日常知识库写入冲突或未发布测试资料。

## 验收发现与边界

1. **综合模式的覆盖提示需要改进。** L2 的合同 `root` 章节只是“星桥服务合同（合成测试）”标题。
   答案已引用退款正文，但未单独引用该标题，系统将它计入未覆盖章节，显示“最终回答未引用以下章节：root”。
   同时顶层 `coverage=complete`、`coverage_report.complete=false`，两项指标容易被混淆。
   本例没有发现业务事实遗漏；“完整覆盖”提示口径尚未通过一致性验收。本轮保留该观察项。
2. **页面文件范围目前是单选。** 页面可选择整个知识库或一份文件；精确选择两份文件由 API 的
   `document_ids` 完成，并已在 I1 验证。L1 是全库范围下回答两份文件的事实，不能等同于页面多选文件。
3. 以上验证针对合成资料和列明的案例；没有涵盖大规模文档、复杂多跳推理、跨图片节点推理或全部
   知识库。`real_acceptance=false` 保持不变，没有签署全局真实验收凭据。
