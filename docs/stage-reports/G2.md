## 3. 安全与一致性

- Zilliz 预过滤固定包含 tenant、space、active generation、SERVING、classification、
  permission revision、valid from/to 和 visibility/ACL ARRAY；
- Zilliz 只返回 chunk/version/parent ID 与排名信息，正文由控制面二次授权后读取；
- security watermark 未追平时 `/search` fail-closed；真实 Zilliz adapter 没有 watermark provider
  时返回 0，不会自行伪造 ready；
- checksum 相同的重复 Chunk 在 RRF 后去重；父片段必须再次通过同一授权、时态和 current-version 检查；
- Embedding 不可用时只保留 BM25；Reranker 不可用时回退 RRF，并显式返回 degraded warning；
- `/search` 请求不接受 `tenant_id`、ACL Token 或任意 Zilliz filter 表达式；
- `config/.env` 未被读取到报告、未输出值、未跟踪。
